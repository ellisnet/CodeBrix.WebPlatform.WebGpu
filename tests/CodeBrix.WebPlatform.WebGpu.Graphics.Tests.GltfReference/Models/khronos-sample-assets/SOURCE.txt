SOURCE OF THIS PACK
===================

Every model folder here is a model of the Khronos Group's glTF Sample Assets repository,
https://github.com/KhronosGroup/glTF-Sample-Assets, exactly as that repository holds it at commit
e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea (obtained 2026-11-24); a model folder <Name>/ comes from
https://github.com/KhronosGroup/glTF-Sample-Assets/tree/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea/Models/<Name>.
Of each model only some of its variant folders were taken (glTF, glTF-Binary, glTF-Embedded, and for one
glTF-Quantized; the glTF-Draco variants of two models are in the pack khronos-sample-assets-draco), with the model's own LICENSE.md and metadata.json; its preview pictures and README were not.
No file was edited.

LICENCES. Only models whose metadata.json names CC0-1.0 or CC-BY-4.0 for EVERY part were taken (models whose
metadata also names a logo or trademark licence were left out). The licence texts are the repository's own
files: LICENSES/CC0-1.0.txt and LICENSES/CC-BY-4.0.txt in this folder. Each model's LICENSE.md says which of
them covers it. The attribution lines below are what each model's metadata.json records (part: licence,
(c) year, owner; the artist where one is named).
