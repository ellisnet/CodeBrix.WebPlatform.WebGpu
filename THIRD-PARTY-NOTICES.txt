THIRD-PARTY SOFTWARE NOTICES AND INFORMATION

CodeBrix.WebPlatform.WebGpu is a set of libraries that bring the Rust crates
for WebGPU in the browser to the frontends of CodeBrix.WebPlatform
applications: the CodeBrix.WebPlatform.WebGpu,
CodeBrix.WebPlatform.WebGpu.Graphics and CodeBrix.WebPlatform.WebGpu.Animation
assemblies and their NuGet packages. The assemblies do not incorporate any
third-party source code. Two packages CARRY third-party software, listed
below with where their generated notices are: the CodeBrix.WebPlatform.WebGpu
package carries the wgpu crates and the glam crate (beside codebrix-webgpu,
a crate of this repository, which is covered by its LICENSE), and the
CodeBrix.WebPlatform.WebGpu.Animation package carries the kurbo, peniko,
harfrust, i_overlay, png, usvg and velato crates and the crates they bring
(beside codebrix-webgpu-animation, also this repository's own; its renderer
contains code taken from vello, and inside it a few lines that vello took
from Skia, listed below). The
CodeBrix.WebPlatform.WebGpu.Graphics package carries the crate
codebrix-webgpu-graphics, also this repository's own; three tone-mapping
functions in it and the logic of its Radiance .hdr decoder follow outside
sources, listed below.

Each package depends on CodeBrix.WebPlatform.Core, which is distributed
separately under its own license and is not part of it; the Graphics and
Animation packages also depend on the CodeBrix.WebPlatform.WebGpu package.

Jeremy Ellis and contributors license the CodeBrix.WebPlatform.WebGpu project
to you under the terms set forth in the LICENSE file, which is located at
the root of this repository. The LICENSE covers the code written for this
project. Everything third-party that the repository carries keeps its own
license, as recorded below and in the generated notices.

If you have any questions about any third-party code or services referenced
here, or if you believe that any third-party code has been included in

Three tone-mapping functions - in codebrix-webgpu-graphics, carried by
CodeBrix.WebPlatform.WebGpu.Graphics

  Where:    the WGSL file tone_map.wgsl of the crate codebrix-webgpu-graphics,
            compiled into the crate, and the same curves on the CPU in its
            ToneMapper::map (in the package,
            tools/webgpu-graphics-crates/webgpu-graphics-crates.zip). In this
            repository: src/CodeBrix.WebPlatform.WebGpu.Graphics/Rust/
            codebrix-webgpu-graphics/src/shaders/wgsl/tone_map.wgsl and
            src/lighting/tone_mapper.rs.
  What:     aces_fitted - the matrices and constants of Stephen Hill's fit of
            the ACES RRT and ODT, as in ACES.hlsl of the BakingLab
            repository (https://github.com/TheRealMJP/BakingLab);
            aces_narkowicz - the curve of Krzysztof Narkowicz's "ACES Filmic
            Tone Mapping Curve" (2016); pbr_neutral - the Khronos PBR
            Neutral tone mapper, following pbrNeutral.glsl of
            https://github.com/KhronosGroup/ToneMapping.
  Licenses: aces_fitted MIT (Copyright (c) 2016 MJP); aces_narkowicz offered
            as public domain CC0 or MIT, used under CC0; pbr_neutral
            Apache-2.0. The entries, with the MIT license text in full, are in
            the hand-written file THIRD-PARTY-NOTICES-WebGpuGraphicsCrates.txt,
            which travels with the package (tools/webgpu-graphics-crates/;
            beside the build program as webgpu-graphics-crates/). In this
            repository: src/CodeBrix.WebPlatform.WebGpu.Graphics/Rust/notices.
